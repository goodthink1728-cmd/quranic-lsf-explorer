# Quranic LSF & Tafsir Explorer V6.0

Aplikasi kajian Al-Qur'an terpadu (114 Surat & 6.236 Ayat) berbasis **Linguistik Sistemik Fungsional (LSF)** Halliday, dipadukan dengan **Tafsir Kemenag RI**, **Tafsir Ibnu Katsir**, pendekatan **Nahwu–Balaghah**, dan pemutar **Murottal Al-Qur'an** tersinkronisasi ayat.

## Fitur Utama
- **Direktori 114 Surat & 6.236 Ayat Kemenag RI** (offline-capable melalui Service Worker PWA)
- **Analyzer LSF (3 Metafungsi & 6 Tipe Proses)** dengan tokenisasi kata, akar kata, peran Nahwu, & diagram LSF
- **Komparasi 5 Tafsir** (Kemenag RI, Ibnu Katsir Bi al-Ma'tsur, Lughawi–Balaghi, Adabi Ijtima'i, dan Maqashidi)
- **Murottal Al-Qur'an Tersinkronisasi** dengan aliran ayat otomatis mengikuti suara qari
- **Pustaka & Kamus Dinamis** yang berkembang otomatis seiring sesi kajian Gemini AI
- **Toggle Istilah Arab (`ON / OFF`)** yang tersimpan otomatis

## Pemakaian di HP Android (PWA & APK)
1. Buka URL GitHub Pages aplikasi ini di Chrome Android.
2. Untuk langsung memasang seperti aplikasi native: ketuk **Menu (⋮) → Install app / Tambahkan ke Layar Utama**.
3. Untuk membungkus menjadi file `.apk` siap sebar tanpa Android Studio: masukkan URL GitHub Pages ke [PWABuilder](https://www.pwabuilder.com/) → **Package for Stores → Android** → unduh file `.apk`.
